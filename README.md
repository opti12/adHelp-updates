# adHelp 애플리케이션

**Active Directory (AD) 관리 및 헬프데스크 지원을 위한 유틸리티 프로그램**

`adHelp`는 AD 사용자 계정 잠금 해제, 비밀번호 재설정, 그룹 조회 등 빈번한 헬프데스크 업무를 간소화하고, 보안을 유지하면서 관리 도구(`ClientDevices.msc`)를 쉽게 실행할 수 있도록 돕는 Windows 데스크톱 애플리케이션입니다.

## 주요 기능

### 1. 사용자 계정 관리
*   **사용자 검색**: ID (eMail ID)으로 AD 사용자를 신속하게 검색합니다.
*   **상세 정보 조회**: 이름, 부서, 이메일, 계정 상태(활성/잠금/만료) 등을 한눈에 확인합니다.
*   **계정 잠금 해제 (Unlock)**: 잠긴 계정을 즉시 해제합니다.
*   **비밀번호 재설정 (Password Reset)**: 도메인 정책에 맞는 안전한 새 비밀번호로 재설정하거나, 임의의 강력한 비밀번호를 생성하여 적용합니다. (다음 로그인 시 변경 옵션 지원)
*   **자격 증명 검증**: 사용자의 현재 비밀번호가 유효한지 테스트할 수 있습니다.

### 2. 그룹 관리
*   **그룹 멤버십 조회**: 특정 사용자가 소속된 모든 AD 그룹 목록을 확인합니다.
*   **클립보드 복사**: 그룹 목록을 텍스트로 복사하여 문서화나 티켓 처리에 활용할 수 있습니다.

### 3. BitLocker 복구 키 조회
*   **컴퓨터명 또는 Key ID로 조회**: PC 이름 일부만 입력해도 후보 목록에서 고를 수 있습니다. 전화로 들은 이름이 부정확하거나 `-1`, `-2` 접미사를 놓친 경우에 유용합니다.
*   **전체 복구 키 표시**: `dsa.msc`의 BitLocker 복구 탭과 동일하게 해당 PC의 모든 복구 키를 생성일 내림차순으로 보여줍니다. 최신 키가 항상 유효한 것은 아니므로 어떤 항목도 숨기지 않습니다.
*   **정확한 특정**: 복구 화면에 표시된 Key ID로 조회하면 해당 볼륨의 키 1건만 나옵니다.
*   **복사**: 선택 행을 메일에 붙여넣을 수 있는 형태로 복사하거나, `Ctrl+C`로 셀 단위 복사가 가능합니다.

> 복구 암호(`msFVE-RecoveryPassword`)는 AD의 confidential 속성입니다. 해당 속성에 대한 `CONTROL_ACCESS` 권한이 위임된 관리자 계정(`-a`)으로 로그인해야 값이 조회됩니다. 권한이 없으면 항목은 보이지만 암호가 빈 값으로 표시됩니다.

### 4. 시스템 관리 도구 연동
*   **Client Devices 관리 (`ClientDevices.msc`)**:
    *   프로그램에 내장된 `ClientDevices.msc` 도구를 관리자 권한으로 실행합니다.

### 5. 보안
*   **안전한 인증**: 비밀번호는 메모리 내에서만 안전하게 처리됩니다.
*   **LDAP 부하 최소화**: 검색은 인덱스를 타는 정확 일치 → 전방 일치 순으로 시도하고, 비인덱스 스캔은 앞 단계가 모두 실패했을 때만 수행합니다. 모든 쿼리에 결과 수·클라이언트·서버 시간 제한이 걸려 있습니다.
*   **감사 로그**: BitLocker 복구 키 조회는 관리자 계정과 대상, 건수가 로그에 기록됩니다. 복구 암호 자체는 기록되지 않습니다.

## 시스템 요구사항

*   **OS**: Windows 10/11 또는 Windows Server
*   **Framework**: .NET Framework 4.7.2 이상
*   **네트워크**: Active Directory 도메인 컨트롤러와 통신 가능한 환경

## 설치 및 실행

1.  배포된 `adHelp.exe` 파일을 다운로드합니다.
2.  프로그램을 실행하고, 필요한 경우 AD 관리 권한이 있는 계정으로 로그인합니다 (프로그램 내부 로그인 기능).
3.  자동 업데이트 기능이 내장되어 있어, 새로운 버전이 배포되면 실행 시 알림을 받습니다.

## 개발 환경

*   **언어**: C# (7.3)
*   **프레임워크**: Windows Forms (.NET 4.7.2)
*   **의존성**: 없음. .NET Framework 기본 어셈블리(`System.DirectoryServices`, `System.DirectoryServices.AccountManagement`, `System.Windows.Forms` 등)만 사용하므로 별도 DLL 없이 `adHelp.exe` 단일 파일로 배포됩니다.
*   **자동 업데이트**: `WebClient` 기반 자체 구현 (`AutoUpdateManager`)
